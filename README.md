# KalaVerse – Indian Art Marketplace 🎨

KalaVerse is a responsive frontend landing page designed to celebrate and support Indian artists by providing a platform to showcase and sell traditional artwork and handmade products.

The project combines modern web design with Indian cultural aesthetics using HTML, CSS, and JavaScript.

---

# 🌟 Features

- Responsive Landing Page
- Modern UI Design
- Mobile-Friendly Navigation
- Hero Section with CTA Buttons
- Featured Indian Art Forms
- Artist Showcase Section
- Marketplace Product Cards
- Smooth Hover Effects
- Semantic HTML Structure
- Responsive Flexbox & CSS Grid Layouts

---

# 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Flexbox
- CSS Grid
- Media Queries
